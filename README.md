# 🗡️ Python Terminal RPG

A simple text-based RPG battle game built using **Python**.

This was created as a beginner project to practice Python fundamentals like loops, conditionals, variables, user input, and game logic.

---

# 🎮 Gameplay

Battle against a powerful monster using different actions:

* ⚔️ **Attack** – Deal damage and earn XP.
* 🛡️ **Shield** – Reduce incoming damage while dealing a smaller counterattack.
* ❤️ **Heal** – Restore health (limited uses).
* 🛒 **Shop** – Spend XP to upgrade your character.
* 🚪 **Quit** – Exit the game.

The objective is simple:

> **Defeat the monster before your health reaches zero.**

---

# 📊 Player Stats

| Stat       | Description                                |
| ---------- | ------------------------------------------ |
| ❤️ Health  | Your remaining life.                       |
| 🛡️ Shield | Reduces incoming damage.                   |
| ⚔️ Attack  | Damage dealt to the monster.               |
| 💚 Heal    | Number of healing charges available.       |
| ⭐ XP       | Earned by attacking and spent in the shop. |

---

# 👹 Monster Stats

* ❤️ Health: **140**
* ⚔️ Attack: **5**

The monster attacks after almost every player action, so choose wisely.

---

# 🛒 Shop

Every upgrade costs **1 XP**.

Available upgrades:

| Upgrade       | Effect                         |
| ------------- | ------------------------------ |
| ⚔️ +3 Attack  | Increase attack damage         |
| 🛡️ +2 Shield | Increase defense               |
| 💚 +1 Heal    | Gain another healing charge    |
| ❤️ +4 Health  | Increase maximum survivability |

---

# 🚀 How to Run

Make sure Python 3 is installed.

Clone the repository:

```bash
git clone https://github.com/PeacefulPolymath/Wizard-Duel.git
```

Go into the project folder:

```bash
cd Wizard-Duel
```

Run the game:

```bash
python file.py
```
